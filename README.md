# Turbo Fix Automotive Website

## 📌 Project Overview
Turbo Fix Automotive is a responsive multi-page website designed for a fictional car repair business. The website provides information about services, company background, and allows users to submit enquiries and contact the business.

This project was developed as part of the WEDE5121 web development module.

---

## 🚗 Website Features

- Home page with business introduction and banner images
- Services page displaying automotive repair services
- About page describing the company
- Enquiry form for service requests
- Contact form for general communication
- Image gallery elements across pages
- Responsive layout with images and navigation menu
- JavaScript form validation and interactivity
- SEO optimisation (meta tags, keywords, alt text)
